Interfaces for your game, built in pure Luau.

NovaUI is a single-file, dependency-free component library for building in-game menus, HUD panels, and admin tools — windows, tabs, toggles, sliders, dropdowns, and notifications, all included.

Installation

NovaUI ships as a single ModuleScript. No loadstring, no external requests.

  1. Add the module

    Copy NovaUI.lua into a ModuleScript named NovaUI, placed in ReplicatedStorage so any LocalScript can reach it.

  2. Require it from a LocalScript

    Anywhere client-side — typically StarterPlayerScripts.

    local NovaUI = require(game.ReplicatedStorage.NovaUI)
  3. Create your first window

    Everything else — tabs, components, notifications — hangs off the window object.

Quick start

A window with one tab, a toggle, and a slider.

local NovaUI = require(game.ReplicatedStorage.NovaUI)

local Window = NovaUI:CreateWindow({
    Title = "Aurora Client",
    Subtitle = "v1.0.0",
    Theme = "Dark",
})

local Main = Window:CreateTab("Main")

Main:CreateToggle({
    Name = "Infinite Sprint",
    Flag = "InfiniteSprint",
    Callback = function(value)
        print("Sprint:", value)
    end,
})

Main:CreateSlider({
    Name = "Walk Speed",
    Range = {16, 100},
    CurrentValue = 16,
    Callback = function(value)
        -- apply to Humanoid.WalkSpeed
    end,
})

Window & Tabs

Every menu starts with one window. Windows hold a draggable, resizable frame, a tab rail, and a notification stack — created automatically. Drag the diagonal marks in the bottom-right corner to resize; the minimize button next to close collapses the window to just its top bar.

Window:CreateTab(name, icon)

Adds an entry to the tab rail and returns a Tab object. icon is optional — pass an rbxassetid:// string to show a small icon before the label. The first tab created is selected automatically. Every component method below lives on the Tab object.

Window:Destroy()

Disconnects every input connection the window created (dragging, resizing, sliders, keybinds, color pickers) and removes its ScreenGui. Call this when you're done with a window instead of just discarding the reference — otherwise those connections outlive the UI.

Button

Tab:CreateButton({ Name, Callback, Info })

Fires Callback() on click, with a short accent flash for feedback. Info is optional — pass a string to show a small "i" badge that reveals it on hover.

Toggle

Tab:CreateToggle({ Name, CurrentValue, Flag, Callback })

Returns { Set, Get }. If Flag is provided, the current value is mirrored into NovaUI.Flags[Flag].

Slider

Tab:CreateSlider({ Name, Range, Increment, CurrentValue, Flag, Callback })

Range is a {min, max} pair. Drag the thumb or click anywhere on the track; the value snaps to Increment. The thumb grows slightly while held for clearer feedback.

Dropdown

Tab:CreateDropdown({ Name, Options, CurrentOption, Flag, Callback })

Returns { Set, Get, Refresh } — call Refresh(newOptions) to repopulate the list at runtime. The chevron on the right rotates to show open/closed state.

Multi-select mode

Pass MultiSelect = true and optionally CurrentOptions = {...}. Clicking an option toggles it on or off instead of closing the list — checkmarks show what's selected. Get() returns an array; Callback(list) fires on every toggle.

Input

Tab:CreateInput({ Name, PlaceholderText, DefaultText, Flag, Callback })

Callback(text, enterPressed) fires when the box loses focus.

Keybind

Tab:CreateKeybind({ Name, CurrentKeybind, Flag, Callback })

Click the key field, then press any key to bind it. Returns { Set, Get }; Callback(keyCode) fires on rebind.

ColorPicker

Tab:CreateColorPicker({ Name, CurrentColor, Flag, Callback })

Click the swatch to expand three RGB sliders. Returns { Set, Get }; Callback(color) fires as each channel is dragged.

Paragraph & Divider

Tab:CreateParagraph({ Title, Content })

A card for longer descriptive text — instructions, changelog notes, warnings — that grows to fit its content instead of clipping. Title is optional.

Tab:CreateDivider()

A plain 1px separator line, for breaking up a tab without a section label.

Notify

NovaUI:Notify({ Title, Content, Duration, Type })

Stacks a card in the top-right of the screen — click one to dismiss it early, or wait for it to fade after Duration seconds (default 4). Only the 5 most recent stay on screen. Type tints the left edge — "Success", "Warning", or "Danger" — and defaults to the accent color.

Performance

A few deliberate choices keep NovaUI cheap to run alongside whatever else is happening in the game.

One shared drag dispatcher per window

Sliders, the ColorPicker's RGB channels, and the resize handle all need live mouse-move tracking while held. Rather than each one opening its own UserInputService connections, every draggable registers with a single dispatcher the window already owns. Connection count stays flat no matter how many sliders or pickers a menu has — it doesn't scale with UI size.

Change-gated updates

Dragging a slider fires mouse-move events far more often than the value actually changes once rounded to its increment. Every value setter checks against the current value first and skips the tween, the flag write, and the callback entirely when nothing changed.

Cached TweenInfo

TweenInfo objects are immutable, so the same handful of (duration, style, direction) combinations — reused on every hover, click, and notification — are built once and cached rather than reallocated per call.

Window:Destroy()

Every connection a window creates is tracked internally. Calling Window:Destroy() disconnects all of them and removes the ScreenGui, instead of leaving orphaned listeners behind if you discard a window reference without cleaning up.

Flags & state

Any component given a Flag mirrors its current value into NovaUI.Flags[Flag], so the rest of your codebase can read it without holding a reference to the component itself.

if NovaUI.Flags["InfiniteSprint"] then
    -- ...
end

Config export & import

Save a user's settings as a plain JSON string and restore them later — built on HttpService:JSONEncode/JSONDecode only, with no filesystem or executor-specific APIs involved. Where you persist that string (a DataStore, your own backend) is up to you.

NovaUI:ExportConfig()

Serializes NovaUI.Flags to a JSON string. Color3 and Enum.KeyCode values round-trip correctly.

NovaUI:ImportConfig(json)

Decodes a string produced by ExportConfig back into NovaUI.Flags. Returns true on success. Note this updates the stored values only — call each component's own Set() if you need the visible UI to reflect the restored state too.

Changelog

v1.5.0

New Paragraph and Divider components. Fixed a bug where CreateLabel's fixed height clipped wrapped multi-line text instead of growing to fit it.

v1.4.0

Performance pass. Sliders, the ColorPicker's RGB channels, and the resize handle previously each opened their own UserInputService connections — a menu with many sliders meant many always-on listeners. They now share one drag dispatcher per window, so connection count is flat regardless of how many components exist. Redundant mid-drag tweens and callbacks are skipped when a value hasn't actually changed, and TweenInfo objects are cached instead of reallocated on every hover.

v1.3.1

Visual refinement pass: a growing accent indicator on the selected tab, an actual drag thumb on sliders, a rotating chevron on dropdowns, and a subtle top-highlight bevel on every card for a bit of depth against the flat background.

v1.3.0

Three new theme presets (Ocean, Amethyst, Emerald) plus full custom theme tables, tooltips via Info on buttons, multi-select dropdowns, and Window:Destroy() for proper connection cleanup.

v1.2.0

Resizable windows, a ColorPicker component, tab icons, and safe config export/import via NovaUI:ExportConfig() / ImportConfig() — no filesystem or executor APIs involved.

v1.1.0

Hover feedback on every interactive element, a minimize button alongside close, a scale-and-fade entrance animation, a soft window shadow, colored notification types, and the new Keybind component.

v1.0.0

Initial release — window, tabs, buttons, toggles, sliders, dropdowns, inputs, and notifications.
