NovaUI v6.0 "Lumen"

A depth-layered, physics-animated Roblox UI library. 22 themes, 37 components, zero external assets.

⚡

Fast

TweenInfo pool, local aliases, memoised layout pass.

🎨

22 Themes

From Dark to Sakura. Register your own in one call.

📱

Mobile-first

Auto-detects touch, repositions window, scales UI.

🔑

KeySystem

Built-in key gate with webhook check support.

💾

Config save

JSON export/import; auto-saves flag state.

🛡️

Reporter

Auto error reporting to Discord on load failure.

Load it

Luau
local NovaUI = loadstring(game:HttpGet("https://raw.githubusercontent.com/you/repo/main/NovaUI.lua"))()
ℹ
HTTP Requests must be enabled in your game's settings (Game Settings → Security → Allow HTTP Requests).

Create a window

Luau
local Window = NovaUI:CreateWindow({
    Title    = "My Script",
    Subtitle = "v1.0",
    Theme    = "Dark",
})

local Tab = Window:CreateTab({ Name = "Main" })

Tab:CreateButton({
    Name     = "Click Me",
    Callback = function()
        NovaUI:Notify({ Title = "Hello!", Content = "Button pressed.", Type = "Success" })
    end,
})

Quick Start

A complete working script in under 30 lines.

Luau — complete example
-- Load NovaUI
local NovaUI = loadstring(game:HttpGet("https://raw.githubusercontent.com/zurai02/NovaUI/main/NovaUI.luau"))()

-- Window
local Win = NovaUI:CreateWindow({ Title = "Hub", Theme = "Amethyst" })

-- Tab
local Tab = Win:CreateTab({ Name = "Combat" })

-- Toggle
Tab:CreateToggle({
    Name    = "Auto Farm",
    Default = false,
    Flag    = "AutoFarm",
    Callback = function(val)
        print("Auto Farm:", val)
    end,
})

-- Slider
Tab:CreateSlider({
    Name    = "Walk Speed",
    Min     = 16, Max = 200, Default = 16,
    Flag    = "WalkSpeed",
    Callback = function(v)
        game.Players.LocalPlayer.Character.Humanoid.WalkSpeed = v
    end,
})
✦
Flags are optional string keys. Set them to enable config save/load — NovaUI remembers the value across sessions automatically.

Reporter

Auto-loads NovaUI and fires a Discord webhook if anything goes wrong. Replace the three URLs and you're done.

Setup

reporter.luau — top section
local NOVA_URL    = ""   -- raw URL to NovaUI.lua
local ICONS_URL   = ""   -- raw URL to Icons.luau  (optional)
local WEBHOOK_URL = ""   -- Discord webhook URL    (optional)

Load via loadstring

Luau
local NovaUI = loadstring(game:HttpGet("YOUR_REPORTER_URL"))()

Error paths

The reporter handles three failure cases. Each fires the webhook and shows an in-game error window (no NovaUI required).

HTTP failureNOVA_URL unreachable after 3 retriesWebhook
Compile errorSource downloaded but loadstring() failedWebhook
Runtime errorCompiled but threw on executionWebhook
ℹ
User IDs are never sent raw. The reporter applies FNV-1a 32-bit hashing — the webhook receives an 8-char hex fingerprint like a3f29c11.
✦
Icons fallback — if ICONS_URL is set, the drawn icon module loads only when NovaUI fails. It is skipped entirely on success.
Docs/API Reference/CreateWindow
API Reference

CreateWindow

Creates the root window. Returns a Window object used to create tabs and access the config API.

Signature
NovaUI:CreateWindow(cfg: WindowConfig) -> Window

Parameters

KeyTypeDescription
Title*stringWindow header text.
Subtitle?stringSmaller text beneath the title.
Theme?string | tableTheme name ("Dark") or a custom theme table. Default: "Dark".
Size?UDim2Override window size. Auto-sized for mobile when omitted.
Position?UDim2Initial position. Centered when omitted.
ToggleKey?Enum.KeyCodeKey to show/hide window. Default: RightControl.
ConfigAutoSave?booleanPersist flag values automatically. Default: false.

Window methods

:CreateTab(cfg)Add a tab to the sidebar. Returns a Tab object.
:Destroy()Remove the window and all its instances.
:Toggle()Show or hide the window.
:SetTheme(name)Switch theme at runtime.
:ExportConfig()Returns a JSON string of all flag values.
:ImportConfig(json)Restores flag values from a JSON string.

Docs/API Reference/Notify
API Reference

Notify

Push a glass-card toast notification. Up to 6 stack at once; the oldest is dismissed to make room.

Luau
NovaUI:Notify({
    Title    = "Auto Farm",
    Content  = "Started successfully.",
    Type     = "Success",  -- Success | Danger | Warning | Info
    Duration = 4,           -- seconds
})

-- Shorthand helpers
NovaUI:NotifySuccess("Title", "Content")
NovaUI:NotifyError("Title", "Content")
NovaUI:NotifyWarn("Title", "Content")
NovaUI:NotifyInfo("Title", "Content")
✦
When NovaUI.Icons is assigned, the icon slot uses a drawn icon (check, error_, warning, info) instead of a Unicode glyph.

KeySystem

Gate your script behind one or more keys. The window is hidden until the correct key is entered.

Luau
Window:KeySystem({
    Title           = "Authentication",
    Subtitle        = "Enter your key to continue.",
    Key             = { "NOVA-ABCD-1234", "NOVA-EFGH-5678" },
    CorrectCallback = function() print("Unlocked!") end,
    WrongCallback   = function() print("Bad key.") end,
    GetKey          = "https://discord.gg/example", -- optional link
})

Webhook validation

Point WebhookURL at an endpoint that returns {"valid": true} to validate keys server-side.

Luau
Window:KeySystem({
    Title      = "Key Gate",
    WebhookURL = "https://your-api.com/validate",
    -- Key table is ignored when WebhookURL is set
})

Docs/Customisation/Icons
Customisation

Icons

50+ drawn icons, zero asset IDs. Pure Roblox Frame geometry — works in any game.

Load & assign

Luau
local Icons = loadstring(game:HttpGet("ICONS_URL"))()
NovaUI.Icons = Icons   -- enables drawn icons in Notify, etc.

API

Icons:Get(name, size, color)Returns a Frame or ImageLabel you can parent anywhere.
Icons:Has(name)Returns true if the named icon exists.
Icons:List()Returns a sorted array of all drawn icon names.

Example

Luau
local frame = Icons:Get("search", 18, Color3.fromRGB(200, 200, 255))
frame.Parent = someGui
ℹ
Icons also has an Id table with 100+ Roblox system asset IDs keyed by name, for games where asset IDs are preferable.

Config System

Every flagged component writes to NovaUI.Flags. Export, import, or auto-save the whole state in one call.

Luau
-- Read a value by its flag key
print(NovaUI.Flags["WalkSpeed"])   -- e.g. 75

-- Export all flags as JSON
local json = NovaUI:ExportConfig()

-- Restore from JSON
NovaUI:ImportConfig(json)

-- Auto-save on every flag change (pass in CreateWindow)
local Win = NovaUI:CreateWindow({ ConfigAutoSave = true, ... })
⚠
Color3 and EnumItems are serialized automatically via a typed wrapper. You don't need to stringify them manually.

NovaUI Lite

A slim fallback library (~450 lines) with the same API surface. Loads in under 5 ms. No depth effects, no tweens.

Auto-fallback pattern

Luau
local NovaUI = loadstring(game:HttpGet(NOVA_URL))()
           or loadstring(game:HttpGet(LITE_URL))()

What's included

All 37 componentsHeavier ones stub gracefully — code never errors.✓
3 themesDark, Light, Midnight. All 22 full-NovaUI names aliased.✓
Notify + DialogSame API, no glass/blur effects.✓
KeySystemPlain modal input, same callback shape.✓
Config stubsSaveConfig / LoadConfig are no-ops — won't crash callers.✓
Depth effectsTopHL, SurfaceGrad, ShineLayer, GlowRing stripped.✗
TweensAll transitions are instant.✗

Mobile Support

NovaUI detects touch devices at CreateWindow time and adapts automatically. No extra config needed.

What adapts

Window sizeClamps to viewport minus a safe margin.Auto
Window positionSnaps to top-left on mobile instead of centering.Auto
NotificationsSlide up from bottom on touch devices.Auto
DragTouch input handled alongside mouse on all draggable elements.Auto
Slider thumbLarger hit target on touch.Auto
✦
The mobile check is memoised per window. Call IsMobile() inside scripts to branch on the same result NovaUI used.
